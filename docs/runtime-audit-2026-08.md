# Runtime 审计与整改清单（2026-08-23）

本清单覆盖播放器启动、整体打包、画面布局、剧情流程和声音行为。`已修复` 表示代码与自动化回归均已覆盖；外部项目素材本身是否可访问不属于 Runtime 可独立保证的范围。

## 启动与整体打包

| 状态 | 原问题 | 整改结果 |
| --- | --- | --- |
| 已修复 | 生产构建固定使用 `/gal_web_runtime/`，ZIP、GitHub Pages 子路径和本地静态服务器不能统一工作 | 开发服务保留子路径，生产构建默认使用 `./` 相对基址；favicon 同样跟随 `BASE_URL` |
| 已修复 | 预载器只接受 HTTP URL，离线包中的 `assets/...` 完全不会预载 | 图片和音频预载均支持相对路径、HTTP、data URL 和 blob URL |
| 已修复 | 启动仅预载图片，没有等待首场景关键资源，也没有进度反馈 | 启动等待首场景背景、立绘、CG、BGM 和首条语音；展示真实进度与当前阶段 |
| 已修复 | 一次性阻塞加载全项目素材，长篇项目启动成本不可控 | 首章关键资源作为启动门槛，其余图片后台预热；进入场景时按真实 jump/choice 分支预载下一节点 |
| 已修复 | 资源失败只留下黑屏或破图，没有可见反馈 | 场景具备视觉兜底，预载失败显示资源数量；CG 加载失败会自动跳过而不是卡死 |
| 已修复 | Generator 即使下载失败也把 manifest 改成本地路径，最终导出“看似成功、实际 404”的不完整包 | 离线 ZIP 与 GitHub 发布均在输出前校验远程下载和最终 manifest，缺任意文件立即明确失败 |

## UI、缩放与手机适配

| 状态 | 原问题 | 整改结果 |
| --- | --- | --- |
| 已修复 | 全局按 1920×1080 缩放根字号，1440 桌面只有 12px，390 手机只有 8px | 删除全局字体缩放；文字保持最小 16px，艺术资源独立缩放 |
| 已修复 | `100vh` 与固定画布忽略移动浏览器地址栏和刘海安全区 | 使用 `100dvh`、`env(safe-area-inset-*)` 和横竖屏断点 |
| 已修复 | 手机工具按钮约 30×22px，难以阅读和点击 | 主要触控目标保持 40–52px；工具栏可横向容纳，文本区独立滚动 |
| 已修复 | 对话框、人物、CG 共用绝对尺寸，窄屏溢出或互相遮挡 | 对话框按视口宽高约束；人物以对话框上沿为基准；全屏与卡片 CG 使用不同自适应策略 |
| 已修复 | 标题、设置、存读档、记录和结局页视觉语言不一致，覆盖页打开时底层变黑 | 统一深色玻璃表面和层级；模态页保留标题或当前游戏画面，关闭后返回原入口 |
| 已修复 | 失败背景直接消失成纯黑，标题菜单在手机上没有稳定布局 | 增加渐变兜底、遮罩层、内容约束和手机底部菜单布局 |
| 已修复 | 粒子每次渲染调用随机数，位置跳变且违反 React purity | 粒子使用稳定的确定性分布；减少动态效果偏好下关闭非必要动画 |
| 已修复 | 缺少键盘基本控制，按钮焦点时空格会误推进剧情 | Space/Enter/右方向键推进、A 切自动、Escape 关闭模态；表单和按钮焦点不会触发剧情快捷键 |

| 已修复 | 只画已解锁节点，玩家看不出共通线、路线和独立结局的整体结构 | 始终显示完整真实图；未探索节点锁定并隐藏标题，章节类型以中文标识 |

| 已修复 | 流程图直接展示内部英文 key 和“选择”菱形，连接关系难读 | 节点使用章节标题、共通/路线/结局语义；玩家选项显示在带箭头的分支连线上 |
| 已修复 | 点击节点直接跳转场景，可绕过选择和变量条件 | 流程图改为只读进度视图；点击仅打开章节信息，不再改变播放位置 |
| 已修复 | BFS 最长深度在循环边上可能反复更新，孤立节点会形成极长单列 | 使用有界可达层级；回边走侧边通道，孤立内容按每层四项归组 |

## 声音与命令播放

| 状态 | 原问题 | 整改结果 |
| --- | --- | --- |
| 已修复 | 打开设置、存档、记录或流程图会因为 screen 改变而暂停/重建 BGM | 基础播放画面和模态导航分离，游戏模态期间 BGM 连续播放 |
| 已修复 | 浏览器阻止自动播放后异常被吞掉，后续用户点击也不会恢复 | BGM 和语音记录待解锁状态，在下一次真实键盘/指针手势重试 |
| 已修复 | 相同 SE 连续触发不会重播；多个同步命令会被 React 批处理折叠 | SE 使用递增事件队列，保留并播放每个事件，允许短音效重叠 |
| 已修复 | 条件分支中的非阻塞命令递归推进主 command index，产生重复、跳过和错误跳转 | 条件命令改为显式队列；阻塞命令结束后继续分支，再返回主场景；队列可随存档恢复 |
| 已修复 | 对话记录虽然保存 voice 字段，但没有重播入口 | 有语音的记录显示重播按钮，同一音频可以重复播放 |
| 已修复 | 页面退到后台后声音继续播放或恢复顺序不一致 | `visibilitychange` 统一暂停，回到前台时只恢复仍有效的 BGM/语音 |

## 验收证据

- `npm run lint`：通过。
- `npm run build`：通过，产物引用为 `./assets/...`。
- Chromium 1440×900：标题、设置返回、对话、完整 5 节点分支图、条件分支、连续双 SE、记录语音重播、半屏 CG、独立结局 CG 均通过。
